# Claude Starterkit

Ein Starterkit für [Claude Code](https://claude.com/claude-code): Skills für Source-/Strata-Modding,
3D-Scans und Audio. Anleitung: **[peaj.de/bday](https://peaj.de/bday)**

A starter kit of Claude Code skills for Source / Strata Source modding, photogrammetry and audio work.

## Install

In Claude Code, type:

> Installiere die Skills von peaj.de/bday

The page contains the install steps for Claude (section "Installation instructions for Claude Code").

## Contents

| Path | What it is |
|---|---|
| `skills/onboarding/` | `/onboarding`: get-to-know-you session, writes a project CLAUDE.md, suggests first tasks |
| `templates/user-CLAUDE.md` | Personal preferences, installed to `~/.claude/CLAUDE.md` (merged, never overwritten) |
| `index.html` | The welcome page served at peaj.de/bday (GitHub Pages) |
