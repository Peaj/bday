Alles Gute zum Geburtstag!

Dieses Kit macht Claude zu deinem Assistenten für deine Projekte: Portal-Mod, Strata-Port, 3D-Scans, Sound und Musik. Claude nimmt dir die lästige Arbeit ab. Die kreativen Entscheidungen bleiben bei dir.

So legst du los

  1. Geschenk einlösen Auf claude.ai anmelden (oder ein Konto erstellen) und dort dein Geschenk einlösen. Das geht nur im Browser, nicht in der App.
  2. Claude Desktop installieren Unter claude.ai/download herunterladen, anmelden und oben zum Tab Code wechseln. Falls die App nach „Git for Windows“ fragt: installieren. Das brauchst du später sowieso für deine Backups.
  3. Kit installieren Eine neue Session starten (der Ordner ist dafür egal) und eingeben: Installiere die Skills von peaj.de/bday Claude zeigt dir, was es macht, und fragt vorher nach.
  4. Kennenlernen Noch eine neue Session starten, diesmal mit deinem Mod-Ordner als Ordner, und eingeben: /onboarding Claude schaut sich erst nur um (ohne etwas zu ändern), stellt dir ein paar Fragen und schlägt dir dann erste Aufgaben vor.

Was im Kit steckt

/onboarding

Claude lernt deine Projekte kennen und schreibt sich Notizen (CLAUDE.md), damit es beim nächsten Mal noch Bescheid weiß.

/version-control

Backup und Git einrichten, Schritt für Schritt erklärt. Am besten bevor du groß umbaust.

/strata-port

Hilft beim Umzug auf Strata Source: vergleicht alte und neue Maps und findet, was sich bei Instances und Entities geändert hat.

/pbr-materials

Aus deinen Scan-Texturen PBR-Materialien für Strata bauen, ohne jede Datei von Hand anzufassen.

Dazu kommt Hintergrundwissen zu Source und Strata, das Claude automatisch nutzt, und eine Datei mit deinen Vorlieben: Claude spricht Deutsch, erklärt statt zu fachsimpeln und trifft keine kreativen Entscheidungen für dich.

Probier mal

Warum funktioniert diese Instance nach dem Kompilieren in Strata nicht mehr? Richte mit mir Git ein – ich hab davon keine Ahnung. Schreib mir ein Blender-Skript, das meine Scans aufräumt und LODs erzeugt. Bau mir ein VST-Plugin: ein dreckiger Bitcrusher für meine Gitarre. Erklär mir, was du gerade gemacht hast.

Gut zu wissen

  • Claude fragt, bevor es Dateien ändert oder Befehle ausführt. Du kannst jederzeit Nein sagen.
  • Esc stoppt Claude sofort.
  • „Warum?“ oder „Erklär mir das“ ist immer eine gute Antwort.
  • Ein Thema pro Session hält Claude fokussiert. Was es über dein Projekt wissen muss, steht in der CLAUDE.md.
  • Claude kann sich irren, gerade bei Strata-Details. Im Zweifel entscheidet der Test in Hammer, und den Compile-Log kannst du Claude zeigen.
  • Eine Aufgabe kommt immer wieder? Sag „Mach daraus einen Skill“.
  • Dein Abo hat ein Nutzungskontingent, das sich regelmäßig wieder auffüllt. Große Aufgaben verbrauchen mehr davon.

Installation instructions for Claude Code

The user asked you to install the skills from this page. The kit lives in the public repository https://github.com/peaj/bday. Talk to the user in German. On Windows, ~ means %USERPROFILE%.

  1. Tell the user in two or three sentences what you'll do: download the kit, copy the skills to ~/.claude/skills, and set up a personal preferences file. Nothing in their projects is touched.
  2. Get the files into ~/.claude/bday: if git is available, git clone https://github.com/peaj/bday ~/.claude/bday (or git -C ~/.claude/bday pull if it already exists). Without git, download https://github.com/peaj/bday/archive/refs/heads/main.zip with curl.exe -L to a temporary folder, extract it (tar -xf) and copy the extracted folder's contents to ~/.claude/bday.
  3. Copy every folder in ~/.claude/bday/skills/ to ~/.claude/skills/<same name>/. If a folder with that name already exists and differs, show the user what would change and ask before replacing it.
  4. Personal preferences: if ~/.claude/CLAUDE.md does not exist, copy ~/.claude/bday/templates/user-CLAUDE.md there. If it exists, do not overwrite it: show the differences, propose a merge and apply it only with the user's approval. Briefly tell the user in German what this file says and that they can edit it anytime.
  5. Check the result: list the installed skills (each folder must contain a SKILL.md).
  6. Finish in German: installation done, which skills are installed, and the next step: start a new session, choose the mod folder as the session's folder, and type /onboarding. Explain that the new session is needed so the skills load.

Updates: when the user asks to update the kit, refresh ~/.claude/bday the same way and repeat steps 3–5, showing what changed.

Do not change anything else on the system during installation and don't run any scripts from the repository.
